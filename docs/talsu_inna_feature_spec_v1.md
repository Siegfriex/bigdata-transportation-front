# A. 회원 / 인증 관리

## A-1. 비회원 이용

**기능명: 비회원 체험 진입**  
기능 설명: 사용자가 회원가입 없이 지도 메인, 샘플 경로, 샘플 리포트를 체험할 수 있다.  
비고: 실제 위치 기반 탐색, 리포트 저장, 루틴 저장, 알림 기능은 제한한다.

**기능명: 비회원 위치 입력**  
기능 설명: 위치 권한 없이 출발지와 도착지를 직접 입력하여 샘플 탐색을 수행한다.  
비고: GPS 기반 현재 위치 자동 탐색은 제공하지 않는다.

**기능명: 비회원 기능 제한 처리**  
기능 설명: 비회원이 저장, 알림, 과거 리포트, 개인화 기능 접근 시 로그인 유도 모달을 표시한다.  
비고: 지도 탐색과 1회성 리포트 생성은 허용한다.

**상태값:** `비회원`, `로그인유도`, `제한접근`

---

## A-2. 회원가입 / 로그인

**기능명: 소셜 로그인 인증**  
기능 설명: 사용자가 카카오, 구글, 애플 등 외부 계정을 통해 로그인한다.  
비고: 동일 소셜 계정의 중복 가입을 방지한다. 지원 채널은 정책에 따라 조정한다.

**기능명: 기본 프로필 수집**  
기능 설명: 소셜 로그인 제공자로부터 이름, 이메일, 프로필 이미지 등 기본 정보를 수신한다.  
비고: 필수 항목 누락 시 추가 입력을 요구한다.

**기능명: 닉네임 입력**  
기능 설명: 앱 내 리포트 및 AI 챗에서 사용할 사용자 닉네임을 입력한다.  
비고: 2~12자 기준으로 검증한다.

**기능명: 약관 동의**  
기능 설명: 서비스 이용약관, 개인정보 처리방침, 위치정보 이용약관에 동의한다.  
비고: 필수 약관과 선택 약관을 구분한다.

**기능명: 가입 완료 처리**  
기능 설명: 필수 정보 입력 및 약관 동의가 완료되면 회원 상태로 전환한다.  
비고: 가입 완료 후 내 평소 조건 설정 화면으로 이동한다.

**상태값:** `인증전`, `소셜인증완료`, `정보입력대기`, `약관동의대기`, `가입완료`

---

## A-3. 위치 권한 관리

**기능명: 위치 권한 요청**  
기능 설명: 지도 메인 진입 시 현재 위치 기반 탐색을 위해 위치 권한을 요청한다.  
비고: 위치 권한 거부 시 출발지 직접 입력으로 대체한다.

**기능명: 위치 권한 상태 확인**  
기능 설명: 사용자의 위치 권한 상태를 확인하여 지도 초기 상태를 결정한다.  
비고: 허용, 거부, 일시 허용, 시스템 차단 상태를 구분한다.

**기능명: 위치 권한 재요청 안내**  
기능 설명: 위치 권한이 차단된 경우 설정 화면에서 권한 변경 방법을 안내한다.  
비고: OS 설정 이동은 모바일 브라우저 정책에 따라 제한될 수 있다.

**상태값:** `위치권한대기`, `위치허용`, `위치거부`, `위치차단`, `수동입력`

---

# B. 사용자 조건 / 개인화 관리

## B-1. 내 평소 조건 설정

**기능명: 집 주소 등록**  
기능 설명: 사용자가 귀가 목적지로 사용할 집 주소를 등록한다.  
비고: 주소명, 좌표, 사용자 지정 별칭을 저장한다.

**기능명: 회사 / 학교 주소 등록**  
기능 설명: 사용자가 출근 또는 통학 목적지로 사용할 주소를 등록한다.  
비고: 복수 등록을 허용할 수 있다.

**기능명: 자주 타는 노선 등록**  
기능 설명: 사용자가 자주 이용하는 버스 노선, 지하철 노선, 정류장, 역을 등록한다.  
비고: 추후 출근 혼잡 예보와 알림 기능에 활용한다.

**기능명: 혼잡 민감도 설정**  
기능 설명: 사용자가 혼잡을 얼마나 회피하고 싶은지 설정한다.  
비고: 낮음, 보통, 높음 3단계로 시작한다.

**기능명: 도보 허용 시간 설정**  
기능 설명: 사용자가 경로 내 허용 가능한 최대 도보 시간을 설정한다.  
비고: 5분, 10분, 15분, 직접입력을 제공한다.

**기능명: 택시비 상한 설정**  
기능 설명: 마감도착 또는 실패복구 플랜에서 사용할 최대 택시비를 설정한다.  
비고: 0원 선택 시 택시 경로를 제외한다.

**기능명: 따릉이 사용 여부 설정**  
기능 설명: 사용자가 따릉이 또는 자전거 수단을 경로 조합에 포함할지 설정한다.  
비고: OFF 상태에서는 자전거 후보를 생성하지 않는다.

**상태값:** `조건미설정`, `부분설정`, `조건설정완료`, `조건수정중`

---

## B-2. 이동 선호 프리셋 관리

**기능명: 빠른 도착 프리셋**  
기능 설명: 예상 도착시간을 최우선으로 경로 후보를 정렬한다.  
비고: 혼잡도와 비용보다 시간 가중치를 높인다.

**기능명: 덜 붐비는 길 프리셋**  
기능 설명: 혼잡도와 탑승 실패 위험이 낮은 경로를 우선 추천한다.  
비고: 도착시간이 일부 증가할 수 있다.

**기능명: 비용 최소 프리셋**  
기능 설명: 택시비와 추가 비용을 최소화하는 경로를 우선 추천한다.  
비고: 도보나 대기 시간이 증가할 수 있다.

**기능명: 실패위험 최소 프리셋**  
기능 설명: 환승 실패, 탑승 실패, 마감 초과 가능성이 낮은 경로를 우선 추천한다.  
비고: 시간과 비용이 다소 증가할 수 있다.

**기능명: 어떻게든 도착 프리셋**  
기능 설명: 도착 마감시각을 최우선으로, 택시·따릉이·도보를 포함해 가능한 모든 조합을 탐색한다.  
비고: 마감도착 플랜의 기본 프리셋으로 사용한다.

**상태값:** `프리셋미선택`, `빠른도착`, `덜붐빔`, `비용최소`, `실패위험최소`, `마감도착우선`

---

# C. 지도 / 위치 / 조건 입력 관리

## C-1. 지도 메인

**기능명: 지도 초기화**  
기능 설명: 앱 실행 시 현재 위치 또는 기본 지역을 기준으로 지도 화면을 표시한다.  
비고: 위치 권한이 없으면 출발지 입력 유도 상태로 표시한다.

**기능명: 주변 대중교통 마커 표시**  
기능 설명: 현재 위치 주변의 버스정류장, 지하철역, 따릉이 대여소를 지도에 표시한다.  
비고: 마커 유형별 아이콘을 구분한다.

**기능명: 지도 레이어 토글**  
기능 설명: 버스, 지하철, 따릉이, 혼잡, 추천 경로 레이어를 켜고 끌 수 있다.  
비고: MVP에서는 버스, 지하철, 따릉이, 추천 경로를 우선 제공한다.

**기능명: 현재 위치 이동**  
기능 설명: 사용자가 현재 위치 버튼을 누르면 GPS 기준 현 위치로 지도를 이동한다.  
비고: 위치 권한이 없으면 권한 안내 모달을 표시한다.

**기능명: 빠른 상황 진입**  
기능 설명: 출근, 퇴근, 9시까지, 막차, 이번 차, 어느 칸 버튼을 통해 기능별 플로우로 진입한다.  
비고: 버튼 선택 시 조건 입력 화면에 해당 모드가 프리셋으로 적용된다.

**상태값:** `지도로딩`, `지도표시`, `위치미허용`, `마커조회중`, `마커표시완료`, `레이어변경중`

---

## C-2. 지도조건 입력

**기능명: 출발지 입력**  
기능 설명: 현재 위치, 주소 검색, 지도 선택을 통해 출발지를 입력한다.  
비고: 출발지는 필수 입력값이다.

**기능명: 도착지 입력**  
기능 설명: 주소, 장소, 역, 정류장 검색을 통해 도착지를 입력한다.  
비고: 도착지는 필수 입력값이다.

**기능명: 출발시각 설정**  
기능 설명: 현재 출발 또는 예약 출발 시각을 선택한다.  
비고: MVP에서는 현재 출발을 기본값으로 한다.

**기능명: 도착 마감시각 설정**  
기능 설명: 사용자가 반드시 도착해야 하는 시각을 입력한다.  
비고: 입력 시 마감도착 플랜이 활성화된다.

**기능명: 제약조건 입력**  
기능 설명: 택시비 상한, 도보 허용 시간, 따릉이 사용 여부, 혼잡 민감도를 입력한다.  
비고: 회원의 기본 설정값을 초기값으로 불러온다.

**기능명: 경로 탐색 요청**  
기능 설명: 입력 조건을 기반으로 경로 후보 생성을 요청한다.  
비고: 필수값 누락 시 오류 메시지를 표시한다.

**상태값:** `조건입력중`, `필수값누락`, `조건입력완료`, `경로탐색요청`, `탐색실패`, `탐색완료`

---

# D. 실시간 데이터 / 데이터 처리 관리

## D-1. 실시간 데이터 조회

**기능명: 버스 도착정보 조회**  
기능 설명: 선택된 정류장과 노선 기준으로 버스 도착 예정 시간을 조회한다.  
비고: API 실패 시 캐시 또는 오류 안내를 제공한다.

**기능명: 버스 위치정보 조회**  
기능 설명: 버스 차량의 현재 위치와 정류장 접근 상태를 조회한다.  
비고: 지연 원인 추정과 후보 상세 화면에 활용한다.

**기능명: 버스 잔여좌석 / 차내혼잡도 조회**  
기능 설명: 잔여좌석과 차내혼잡도 직접값이 제공되는 경우 해당 값을 조회한다.  
비고: 직접값이 없으면 추정값 생성 플로우로 전환한다.

**기능명: 지하철 도착정보 조회**  
기능 설명: 선택한 역과 방향 기준으로 열차 도착 예정 정보를 조회한다.  
비고: 마감도착, 실패복구, 칸별 생존가이드와 연동한다.

**기능명: 따릉이 대여정보 조회**  
기능 설명: 주변 대여소의 실시간 대여 가능 대수를 조회한다.  
비고: 따릉이 OFF 조건에서는 호출하지 않는다.

**상태값:** `실시간조회대기`, `조회중`, `조회성공`, `일부조회실패`, `조회실패`, `캐시사용`

---

## D-2. 정적 / 패턴 데이터 처리

**기능명: 지하철 혼잡도 패턴 조회**  
기능 설명: 역, 방향, 요일, 시간대 기준의 지하철 혼잡도 패턴을 조회한다.  
비고: 실시간 값이 아니라 과거 패턴 기반임을 표시한다.

**기능명: 버스 승하차 패턴 조회**  
기능 설명: 노선, 정류장, 요일, 시간대 기준의 버스 승하차 패턴을 조회한다.

# E. 탑승가능성 리포트

## E-1. 이번 차 탑승 판단

**기능명: 이번 차 탑승 가능성 계산**  
기능 설명: 현재 정류장 또는 역 기준으로 이번 버스·지하철을 실제로 탈 수 있는지 판단한다.  
비고: 버스는 잔여좌석·혼잡도 직접값을 우선 사용하고, 지하철은 혼잡도 패턴과 도착정보를 결합한다.

**기능명: 다음 차 비교**  
기능 설명: 이번 차와 다음 차의 도착시간, 혼잡도, 잔여좌석, 실패위험을 비교한다.  
비고: 다음 차 정보가 없으면 이번 차 기준 판단만 제공한다.

**기능명: 탑승 추천 행동 생성**  
기능 설명: 시스템은 탑승, 대기, 우회, 재탐색 중 하나의 추천 행동을 생성한다.  
비고: 추천 행동은 리포트 상단에 1문장으로 표시한다.

**기능명: 탑승 가능성 신뢰도 산출**  
기능 설명: 직접값, 추정값, 패턴값 여부에 따라 판단 신뢰도를 산출한다.  
비고: 직접값 기반은 신뢰도 높음, 패턴 기반은 중간 또는 낮음으로 표시한다.

**상태값:** `탑승판단대기`, `탑승가능`, `대기추천`, `우회추천`, `판단불가`, `신뢰도낮음`

**기능명: 다음 차 정보 표시**  
기능 설명: 다음 차의 도착 예정 시간, 잔여좌석, 혼잡도, 대기 이득을 표시한다.  
비고: 버스는 첫 번째·두 번째 차량 비교, 지하철은 다음 열차 비교를 기본으로 한다.

**기능명: 추천 이유 표시**

비고: 동일 조건을 유지한 채 후보 재탐색을 수행한다.

# F. 칸별 생존가이드

## F-1. 칸별 추천 계산

**기능명: 빠른하차 칸 계산**  
기능 설명: 하차역의 출구, 계단, 에스컬레이터, 엘리베이터 위치를 기준으로 빠른하차 칸을 산출한다.  
비고: 빠른하차 정보가 없으면 해당 항목은 표시하지 않는다.

**기능명: 빠른환승 칸 계산**  
기능 설명: 환승역에서 환승 통로와 가까운 칸과 문 번호를 산출한다.  
비고: 환승 없는 경로에서는 비활성화한다.

**기능명: 혼잡회피 칸 계산**  
기능 설명: 시간대별 혼잡도, 빠른하차·환승 쏠림, 사용자 선호를 반영하여 상대적으로 덜 붐빌 가능성이 높은 칸을 산출한다.  
비고: 실시간 칸별 인원 실측이 아닌 경우 “패턴 기반 추천”으로 표시한다.

**기능명: 회피 칸 계산**  
기능 설명: 출구, 계단, 환승 통로에 인접해 혼잡 쏠림이 예상되는 칸을 회피 칸으로 표시한다.  
비고: 회피 칸은 무조건 나쁜 칸이 아니라 혼잡 민감 사용자에게 비추천되는 칸이다.

**기능명: 사용자 선호 반영**  
기능 설명: 빠른 환승, 덜 붐빔, 빠른 하차, 교통약자, 짐 많음 중 사용자의 선호를 반영한다.  
비고: 선호에 따라 추천 칸 순위가 달라진다.

**상태값:** `칸추천대기`, `빠른하차계산완료`, `환승칸계산완료`, `혼잡회피계산완료`, `추천칸확정`, `추천불가`

---

## F-2. 칸별 생존 리포트 표시

**기능명: 추천 칸 표시**  
기능 설명: 사용자가 탑승할 추천 칸과 문 번호를 1~3개 표시한다.  
비고: 우선순위가 높은 칸을 첫 번째로 표시한다.

**기능명: 회피 칸 표시**  
기능 설명: 혼잡 쏠림이 예상되는 칸을 회피 칸으로 표시한다.  
비고: 회피 이유를 함께 표시한다.

**기능명: 추천 이유 표시**  
기능 설명: 추천 칸이 선택된 근거를 자연어로 표시한다.  
비고: 빠른환승 칸과 생존 칸이 다를 경우 차이를 설명한다.

**기능명: 지도 / 노선도 위치 표시**  
기능 설명: 추천 칸을 간단한 열차 도식 또는 노선도 위에 표시한다.

**기능명: 추천 칸 저장**  
기능 설명: 사용자가 자주 타는 경로의 추천 칸을 저장한다.  
비고: 로그인 사용자에게만 제공한다.

**상태값:** `리포트표시`, `추천칸저장`, `저장실패`, `패턴기반표시`, `실시간기반표시`

기능 설명: 정적 데이터와 패턴 데이터의 최신 적재 상태를 확인한다.  
비고: 지하철 혼잡도, 승하차 패턴, GTFS 등에 적용한다.

**기능명: 데이터 매칭 오류 확인**  
기능 설명: 정류장 ID, 역 ID, 노선 ID 매칭 실패 건을 확인한다.  
비고: 지도 표시 오류와 추천 오류의 주요 원인이다.

**상태값:** `정상`, `지연`, `부분장애`, `장애`, `복구중`, `복구완료`

## M-2. 리포트 품질 관리

**기능명: 리포트 생성 로그 확인**

기능 설명: 성공 플랜이 생성되지 않은 조건을 분석한다.  
비고: 서비스 개선과 데이터 보강에 활용한다.

비고: 대회 제출 시 AI 활용 증빙자료로 활용 가능하다.

# O. 핵심 알림 / 공지 정의 목록

사용자 가입이 완료되었을 경우, 가입 완료 알림을 발송한다.

위치 권한이 꺼져 있어 현재 위치 기반 탐색을 사용할 수 없는 경우, 위치 권한 안내 알림을 표시한다.

저장된 출근 루틴 기준 출발해야 할 시간이 가까워졌을 경우, 출발 알림을 발송한다.

선택한 버스의 잔여좌석 또는 탑승 가능성이 낮아졌을 경우, 탑승 변경 알림을 발송한다.

선택한 경로의 예상 도착시각이 마감시각을 초과할 가능성이 높아졌을 경우, 마감 위험 알림을 발송한다.

막차 연결 실패 가능성이 높아졌을 경우, 막차 위험 알림을 발송한다.

환승 실패 가능성이 높아졌을 경우, 환승 위험 알림을 발송한다.

리포트가 저장되었을 경우, 리포트 저장 완료 알림을 표시한다.

실시간 API 장애로 일부 데이터가 추정값으로 대체되었을 경우, 데이터 신뢰도 안내를 표시한다.

서비스 약관 또는 개인정보 처리방침이 변경되었을 경우, 변경 공지를 표시한다.
