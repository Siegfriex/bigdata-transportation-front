**문서 유형:** Data Source & Service Policy Mapping Document  
**서비스명:** 탈수있나  
**플랫폼:** Mobile Web App 중심  
**버전:** v1.0  
**작성 목적:** 기능별 필요 데이터소스, 공공데이터, 사설 API, 데이터 조합·가공·예측 범위, 정책 코드를 일괄 관리하기 위한 문서

## 0. 문서 목적

본 문서는 **탈수있나**의 IA 및 기능명세를 기준으로, 각 기능이 어떤 데이터소스를 필요로 하는지, 어떤 공공데이터·Open API·사설 API를 사용해야 하는지, 그리고 데이터 신뢰도·예측값·개인정보·알림·AI 활용 정책을 어떻게 설계해야 하는지 정리한 정책 문서다.

기존 레퍼런스의 `정책 코드 / 정책분류 / 세부 항목 / 정책 소개 / 정책 내용` 구조를 차용하되, 본 프로젝트에 맞게 다음 영역으로 재구성한다.

1. 사용자/회원 정책
2. 위치정보·개인정보 정책
3. 데이터소스 이용 정책
4. 데이터 신뢰도·예측값 표시 정책
5. 기능별 데이터 매핑 정책
6. Open API / 사설 API 사용 정책
7. AI 활용 정책
8. 알림·공지 정책
9. 대회 가점 및 증빙 정책

## 2. 데이터소스 레지스트리

### 2.1 데이터소스 분류 기준

| 구분 | 정의 | 예시 |
|---|---|---|
| 직접 사용 데이터 | API 또는 파일 값을 그대로 기능에 표시 | 경기도 버스 잔여좌석, 따릉이 대여 가능 대수 |
| 조합 데이터 | 여러 API를 매칭해 새로운 판단값 생성 | 버스 위치 + 도착정보 + 도로속도 |
| 패턴 데이터 | 과거 데이터로 시간대·요일별 패턴 생성 | 지하철 혼잡도, 승하차 패턴 |
| 예측 데이터 | 모델을 통해 미래 또는 현재 미제공값 추정 | 서울 버스 차내혼잡 추정, 환승 실패 확률 |
| 최적화 데이터 | 경로 후보를 시간·비용·위험 기준으로 랭킹 | 마감도착 플랜, 실패복구 플랜 |
| 사설 API | 민간 지도·경로·검색·AI API | Kakao Local, NAVER Maps, Mapbox, OpenAI |
